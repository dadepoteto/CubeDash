# Cube Dash Android

Proyecto Android nativo, sin librerías externas.

## Compilar
1. Abre la carpeta `CubeDashAndroid` en Android Studio.
2. Espera a que Gradle sincronice.
3. Ejecuta `app` en un dispositivo/emulador Android.
4. Para crear el APK: Build > Build APK(s).

Controles: mantener pulsada la pantalla para saltar repetidamente.
Los bloques son plataformas; chocar de frente contra un bloque o tocar un pico hace perder.
